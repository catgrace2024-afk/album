# album

パスワード付きの写真アルバム。

このリポジトリに置いてある写真ファイルは **すべて暗号化済み** で、
パスワードを知らないと中身を見ることはできません（AES-256-CTR + HMAC-SHA256、
鍵は PBKDF2-SHA256 30万回でパスワードから導出）。
復号はブラウザの中だけで行われ、パスワードはどこにも送信されません。

- 公開ページ: `docs/` を GitHub Pages で配信
- 写真の追加: `~/Pictures/会社で見る写真` に入れて `python3 build.py`
- パスワード変更: `パスワードを決める.command` → `python3 build.py`

`.password` はこのリポジトリには入っていません（`.gitignore` 済み・手元だけ）。
